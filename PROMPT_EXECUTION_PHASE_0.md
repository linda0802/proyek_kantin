Checklist:
1. Periksa struktur project React + Vite.
2. Pastikan entry point dan struktur source dapat digunakan.
3. Identifikasi dependency yang sudah tersedia.
4. Rancang struktur folder awal yang diperlukan.
5. Jangan membuat modul Dashboard, POS, Produk, Transaksi, Stok, Laporan, atau fitur lain sebelum Phase 0 disetujui.
6. Jangan menambahkan fitur di luar PRD.
7. Jangan mengubah scope.
8. Jika ada masalah atau informasi yang kurang, laporkan dan jangan menebak.
